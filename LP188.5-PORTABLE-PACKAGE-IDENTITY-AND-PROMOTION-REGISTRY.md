# LP188.5 — Portable Package Identity and Promotion Registry Separation

## Audit result

LP188.3's checked-in certification establishes 254 manufactured and certified county packages, but explicitly says their portable bytes are absent. LP188.4 consequently contains no package hashes and correctly blocks promotion. The runtime county registry is executable configuration, so it remains unchanged and is not reused for promotion metadata.

LP188.5 adds a read-only byte capture tool and a metadata-only artifact family under `reports/lp1885/`. The tool reads each existing `counties/<FIPS>.json` as a `Buffer`, computes SHA-256 directly over that buffer, and only then parses a decoded copy to validate schema, filename FIPS, governed FIPS, and county name. It never writes into the source directory. Outputs use sorted FIPS order, stable JSON keys, UTF-8 without BOM, LF endings, and no timestamp or host path.

The promotion-only registry is evidence, not runtime configuration. It is outside all runtime asset/package registries, no runtime source imports or fetches it, and `GRIDLY_COUNTY_REGISTRY`, `defaultAwarenessAreas`, operational membership, Supabase scope, routing, crossing, address, and roadway loaders are unchanged. Every record remains `NOT_PROMOTED`; owner authorization and activation governance remain separate blockers.

## Exact Windows PowerShell 5.1 handoff

Run from the repository checkout. This installs nothing, rewrites no package, performs no upload, promotion, deployment, or activation, and prints the resulting certification:

```powershell
$ErrorActionPreference = 'Stop'
$Repo = (Get-Location).Path
$Source = 'C:\GitHub\Gridly-Source-Data\Processing\Community-Packages\statewide-identity-v1'
if (-not (Test-Path -LiteralPath $Source -PathType Container)) { throw "LP188.3 package directory not found: $Source" }
if (-not (Test-Path -LiteralPath (Join-Path $Source 'counties') -PathType Container)) { throw "LP188.3 counties directory not found: $Source\counties" }
node (Join-Path $Repo 'tools\lp1885\capture-community-package-identities.mjs') $Source $Repo
if ($LASTEXITCODE -ne 0) { throw "LP188.5 capture failed closed with exit code $LASTEXITCODE" }
Get-Content -Raw -LiteralPath (Join-Path $Repo 'reports\lp1885\lp1885-identity-capture-certification.json')
```
