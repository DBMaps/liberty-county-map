# LP218.1 — Live watched-area geography reconciliation

## Evidence and divergence

LP218 claimed Pecos had 67 inventory records, 67 valid coordinates, 48 watched and 42 rendered. Owner browser acceptance instead observed `reeves-tx`, generation 1, 67 inventory, 67 valid, zero watched, 42 viewport eligible/rendered, and `current` status. Browser acceptance therefore remains open; Family I is **not closed**.

The canonical selected record is a governed PLACE identity (`place-4873493`, PLACE `4873493`, Reeves County) with the complete runtime awareness selector. The Location Context summary is deliberately compact: `{ key/canonicalKey, placeGeoid, label, countyId, coordinates, radiusMiles, source }`; historically its identity fields could be absent and its coordinates can be null while canonical presentation data hydrates. LP218 compared this projection only with the current selected object and then sent the lossy projection to `gridlySelectConsumerVisibleCrossings` when equality failed. `Number(null)` became zero in the distance path, so every valid Reeves crossing was outside a radius centered at `(0,0)`. Viewport rendering independently used the healthy county inventory and therefore still rendered 42.

The LP218 deterministic fixture never exercised that compact/null shape: it supplied preselected watched IDs and asserted 48. That was the precise deterministic/live branch divergence.

## Repair

`getGridlyAwarenessAreaDebugOption` now retains canonical key and PLACE GEOID. `gridlyRejoinCrossingAwarenessSelector` rejoins by canonical identity **and** authoritative county against the canonical awareness registry; it requires exactly one result, so wrong-county, wrong-identity, and ambiguous matches fail closed. Consumer label is diagnostic only. “Town of Pecos” versus “Pecos” did not cause the geographic defect and presentation is unchanged.

The repaired selector is the complete canonical awareness object: canonical key/PLACE, Reeves county, canonical top-level `lat`/`lng`, seven-mile radius, and any canonical geometry/state already present. No inventory, viewport, marker, DOM, previous-county, Pecos, or Reeves fallback was added. C/J persistence and membership resolution are untouched.

The bounded audit adds selector source, attempt/success, both identities, county/label comparisons, coordinate/radius provenance, selector geography, candidate count, and aggregate rejection reasons. It emits no crossing rows.
