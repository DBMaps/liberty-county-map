## Repair contract

The old selector path was compact projection → unique canonical awareness rejoin → use incomplete awareness geography → reject every crossing. The new path is compact projection → unique canonical awareness rejoin → validate the same PLACE occurs exactly once in the governed county registry and includes that county FIPS → resolve that PLACE through the existing LP201 canonical presentation helper → combine the read-only coordinate with the awareness radius → run the shared selector.

Missing identity, duplicate candidates, county disagreement, missing governed membership, absent LP201 target, or invalid target all return a geography-failure sentinel. There is no viewport, map-center, county-centroid, marker, inventory-centroid, first-membership, previous-county, or `(0,0)` fallback. No LP201 coordinate or static geometry is mutated or copied into persistence.

## Numeric parsing
