# LP218.3 — Family I live acceptance and closure

## Decision

**Family I — CLOSED.** Family I was **crossing watched-count propagation**: a governed county could have a healthy crossing inventory, valid crossing coordinates, and visible markers while Location Context falsely displayed `0 crossings watched`. Owner live-browser acceptance reversed both primary failures without collapsing county inventory, valid-coordinate inventory, watched-area eligibility, viewport eligibility, rendered markers, or displayed count.

LP218.3 changes no production behavior. It preserves evidence, reconciles obsolete test expectations, adds a deterministic closure suite, and stops before any other defect family.

## Root-cause and repair chain

1. **LP218:** Location Context had independently reapplied geographic filtering to a lossy compact summary/debug projection while rendering used canonical inventory and viewport paths. LP218 restored one shared watched-count derivation contract.
2. **LP218.1:** canonical identity rejoin became county-qualified and used canonical key or PLACE GEOID plus authoritative county. In Pecos, `canonicalRejoinSucceeded: true` proved identity recovery, but the canonical awareness object still had no usable geography (`selectorLat: 0`, `selectorLng: null`, `missing_geography: 67`). A five-second hydration check did not change the result, excluding an asynchronous hydration race.
3. **LP218.2:** incomplete canonical awareness geography was bridged, read-only, to `data/generated/gridly-statewide-place-presentation-v1.json` through the existing canonical presentation helper. The bridge fails closed on absent, invalid, ambiguous, or county-incompatible authority. It does not overwrite complete canonical awareness geography.
4. **Numeric parsing repair:** JavaScript's `Number(null) === 0` had allowed missing latitude to resemble a valid zero. Optional geographic coordinates now reject null, undefined, and blank values before numeric conversion.

The resulting contracts remain separate:

```text
county inventory
→ valid coordinates
→ reportability / policy
→ authoritative canonical community geography
→ watched-area eligibility
→ displayed watched count

eligible inventory
→ viewport filtering
→ rendered markers
```
