## Review rubric

For every image record hierarchy, density, spacing/alignment, typography/wrapping/capitalization, color/contrast semantics, card/disclosure/icon consistency, action hierarchy, map obstruction, touch-target presentation, state quality, brand polish, portrait balance and desktop derivation.

Use exactly these classifications:

- **LAUNCH PROBLEM:** prevents/misleads a normal traveler or hides a critical state/action; requires evidence and repair.
- **MEANINGFUL POLISH:** conspicuous but journey remains clear; address before launch if bounded.
- **PREFERENCE:** subjective alternative with no material traveler impact; do not churn.
- **LEAVE ALONE:** correct/protected behavior, especially LP240 contracts without new evidence.

## Current static disposition

No visual launch defect is proven without current screenshots. Density, wrapping, sheet/map balance, state quality, and desktop derivation are **MEANINGFUL POLISH candidates**.
