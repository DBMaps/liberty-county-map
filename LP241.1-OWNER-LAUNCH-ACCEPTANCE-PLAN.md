### Smallest safe execution mechanism

Do **not** add a second provider client. Correct the audit fixture artifact in a separately owner-authorized audit-only change by deriving the official county label from the existing canonical FIPS authority, then review the 254 public-government-facility queries before execution. Execution must remain inside the deployed production search UI/provider boundary and be:

- explicitly started by the owner;
- sequential, concurrency `1`, with a visible stop control;
- bounded to an owner-selected batch (recommended operational default: 10, never automatically all 254);

Allowed `result` values are `PASS`, `FAIL`, `REQUIRES_BROWSER`, and `UNAVAILABLE`. `WRONG_RESULT`, wrong county/identity, invalid coordinates, false success, or false `EXACT` is always `FAIL`. A road centerline, ZIP/county centroid, or unrelated highway is never `EXACT`. `REQUIRES_BROWSER` is reserved for rendering, selection, marker, and route-preview/handoff observation; it cannot conceal a deterministic disagreement. `UNAVAILABLE` records a provider/environment inability truthfully and does not pass the gate.
