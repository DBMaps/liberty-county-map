# LP241.5 Box Canyon crossing eligibility/render reconciliation

## Disposition

Box Canyon remains open pending owner-browser acceptance. This change does not merge or declare the community fixed.

## Meaning of the three observed counts

* **6 selected** was the radius result after the shared selector applied its defective policy gates. All six are geographically within seven miles. The selector trusted the manufactured `gridlyClassification=PUBLIC_ROADWAY`, which was defaulted on all six, and reportability ignored the production source's uppercase `POSXING` and `XPURPOSE` fields.
* **1 prior deterministic** was a static test's `TYPEXING === "Public"` subset. It correctly separated source public/private status but did not apply the existing reportable-at-grade requirement. FRA 924451G is source-public but `POSXING=RR Under`, so one is not the full production contract result.
* **0 rendered** is a live marker census, not the awareness-radius count. Map markers additionally depend on zoom policy, actual Leaflet bounds, representative/cap selection, clustering, layer attachment, and asynchronous publication. In this Box Canyon cohort, zero is also the only count compatible with the repaired common public-and-reportable gate; the old capture alone does not prove which extra map condition produced it.

Private crossings remain governed inventory and report targets, but do not make a traveler-facing public-roadway marker or “crossings watched” membership.

## Reconciled contracts and RCA

`gridlySelectConsumerVisibleCrossings` owns static traveler awareness membership: active-county governed inventory, valid coordinates, launch visibility, authoritative public roadway, reportable at-grade highway position, selected awareness geography/radius, and FRA-ID deduplication. It does not promise current marker or viewport membership.

The displayed count flows through `summarizeGridlyAwarenessIntelligenceForDisplay` → `getGridlyBottomPanelAwarenessCrossingCount` → the selector. The count can also take the current summary projection or an active saved-route floor; county-wide mode uses the selector directly.

Map membership flows through `renderCrossings` → `getGridlyPolicyVisibleCrossings`. It shares public-roadway and reportability predicates, then adds county, current zoom/render mode, actual viewport, representative/hard-cap, clustering, and render lifecycle rules. Thus watched and marker consumers share base eligibility intentionally but do not promise equal counts in every camera state.

The remaining defect was at the shared source interpretation boundary: both consumer and marker paths treated a permissively manufactured Gridly class as public authority, while reportability failed to read uppercase FRA package fields. The repair makes `TYPEXING` authoritative when present, retains Gridly classification only as a compatibility fallback, and reads `POSXING`/`XPURPOSE` for reporting eligibility. It does not modify packages, inventory, identity, coordinates, county activation, or reporting availability.

The truthful Box Canyon result for the six seven-mile candidates is therefore **0 watched and 0 eligible crossing markers**. The five private at-grade locations remain reportable crossing locations but are not traveler-visible public crossings; the one public location is an underpass and is not reportable under the existing at-grade contract.

## Statewide impact

The deterministic census of all 254 production packages contains 16,099 governed records: 11,195 source-public, 4,902 source-private, two other/unknown source types, and 9,162 source-public at-grade highway-purpose records. The repair changes presentation eligibility only; it does not remove any inventory or report identity. Regression coverage freezes this census so no statewide removal can be silent.
