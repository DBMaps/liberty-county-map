# LP241.7 Compatibility & Accessibility Launch Certification

**As of:** 2026-08-27  
**Evidence boundary:** deterministic source/tests only; no physical-device, browser-engine, assistive-technology, or installed-PWA execution is claimed.

## 1. Executive result
Gridly's shared source contracts support the critical traveler journeys, and no open deterministic launch blocker remains. One proven accessibility defect prohibited user zoom; the bounded viewport repair is covered by regression tests. Four representative owner runs remain—the minimum evidence needed for actual keyboard/AT, Android rendering, iOS/VoiceOver/safe-area, and installed-PWA behavior.

## 2. Deterministic certification summary
The certifier passes 17 source contracts: language/title, zoom, native controls, focus-visible, reduced motion, safe areas/dynamic viewport, dialogs/live regions/hidden state, Escape/restoration, manual-location fallback, manifest/icons, and service-worker lifecycle. It inventories 197 native interactive elements (130 buttons, 23 inputs, 13 selects, 15 details, 15 summaries, one textarea) and two focusable generic controls requiring bounded runtime keyboard handlers.

## 3. Interactive control / semantics result
**CERTIFIED (source contract).** Essential UI primarily uses native controls. The two generic focusable controls are explicitly inventoried rather than silently treated as native. Native semantics are not decorated with redundant ARIA. Runtime geometry, computed accessible names, and hidden-state behavior remain sampled in owner acceptance.

## 4. Keyboard / focus result

Only a rendered browser traversal can prove final Tab/Shift+Tab order, no trap, and focus survival through dynamic rerenders; OA-1 covers all shared overlays and critical actions once.

## 5. Screen-reader semantic result
**OWNER_ACCEPTANCE_REQUIRED.** The document language/title, landmarks/surface labels, native labels, named icon controls, dialogs, expanded states, live/status regions, and decorative icon hiding are deterministic. No VoiceOver, TalkBack, NVDA, JAWS, Narrator, or accessibility-tree PASS is claimed. Narrator is sampled in OA-1 and VoiceOver in OA-3.

## 6. Map accessibility result
**CERTIFIED (source contract).** Essential traveler meaning has non-map surfaces in Alerts, Know Before You Go, Location Context, Destination Intelligence, crossing details, and community incident cards. Map interaction is not claimed universally accessible; OA-3 fails if any critical journey proves gesture-only essential information.

## 7. Text scaling / reflow result
**OWNER_ACCEPTANCE_REQUIRED.** The prior viewport directive prevented scaling. It now preserves responsive width, initial scale, and `viewport-fit=cover` without limiting user zoom. CSS supplies breakpoints, wrapping/scroll contracts, dynamic viewport units, and bounded overlay scrolling. OA-1 checks desktop 200% zoom pressure; OA-2/OA-3 cover platform large text and long labels.

## 8. Touch / mobile result
**OWNER_ACCEPTANCE_REQUIRED.** Native touch activation, responsive modes, scrollable panels, and non-hover action paths are source-certified. Actual hit-target separation, overlay interception, browser chrome, and fat-finger usability require OA-2 and OA-3.

## 9. Orientation / safe-area result
**OWNER_ACCEPTANCE_REQUIRED.** Active CSS uses all relevant safe-area inset patterns and dynamic viewport units for fixed surfaces. Actual notch, mobile chrome, and rotation repaint remain OA-2/OA-3; no physical iOS evidence is manufactured.

## 10. PWA / standalone result
**OWNER_ACCEPTANCE_REQUIRED.** The manifest parses, requests standalone display, scopes the start URL, and references present 192/512/maskable icons. Service-worker installation/activation/fetch source exists. OA-4 alone covers real installation, standalone navigation, background/foreground, persistence, and cache/update behavior.

## 11. Reduced-motion result
**CERTIFIED.** Active CSS has `prefers-reduced-motion: reduce` rules. Essential state changes are driven by activation/state, not animation completion. No motion-dependent launch blocker was found.

## 12. Color / contrast result
**OWNER_ACCEPTANCE_REQUIRED.** Critical states carry text/status labels and are not intentionally color-only. Static source cannot fully certify computed layered/translucent surfaces or dynamic map tiles; OA-2 includes readable state/non-color observation. Dynamic map-tile contrast is explicitly outside deterministic certification.

## 13. Browser-compatibility result
**OWNER_ACCEPTANCE_REQUIRED.** Storage startup is guarded, geolocation has manual fallback, service-worker/PWA contracts are bounded, modern viewport fallbacks exist, and no essential hover-only contract was found. Real Edge, Chrome Android, Safari/iOS, and installed context execution is represented once each where it proves a distinct engine/input contract.

## 14. Defects found
**LP2417-A11Y-001 (launch-critical, repaired):** `maximum-scale=1.0, user-scalable=no` prohibited user zoom in the shared viewport meta element, affecting text scaling/reflow across first load and every traveler journey. No other proven open compatibility/accessibility defect was found.

## 15. Repairs made
