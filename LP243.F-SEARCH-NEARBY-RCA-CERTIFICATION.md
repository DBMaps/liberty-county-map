## Product contracts

Destination Search and Nearby Places intentionally retain different providers. Destination Search remains general and permits explicit remote intent. For common unqualified searches, the current governed area is a proximity/ranking signal, not a hard boundary. Nearby Places remains radius/category search over `gridly.poi.runtime.v2`.

Selecting any Nearby Places result uses the existing destination action: preserve POI identity, name, coordinates, category, and county context; set/focus that destination; close Search; and invoke the existing route-preview flow. It does not select or mutate Home Area, Awareness Area, county governance, POI data, or routing policy.
