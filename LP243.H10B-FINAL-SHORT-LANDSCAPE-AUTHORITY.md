# LP243.H10B — Final short-landscape authority

## Consolidation RCA

H10A found that H5 through H9 were individually reasonable milestones but remained additive: fixed top and bottom surfaces, reserve arithmetic, an expanded shell-padding rule, fail-open geometry, and floating KBYG geometry all remained in the cascade. Later rules compensated for earlier geometry rather than replacing it, so the collapsed command could still reserve map space. H10B removes those active H5–H9 blocks and establishes one short-landscape authority.

## Final contracts

The only production authority is `@media (orientation: landscape) and (max-height: 500px)`. Its structural shell is `compact top / minmax(0, 1fr) map`. The collapsed command reserves zero layout height: shell padding-bottom is zero and both the 44px disclosure and command workspace are fixed overlays. Expansion translates the existing bottom workspace over the mounted map and reveals the existing Location Context/Search row plus one existing action row.

KBYG reuses its current handle and interaction panel but occupies the full usable fixed viewport, scrolls internally, suppresses underlying chrome, and leaves the Leaflet map mounted. Search and V2 sheets retain their lifecycle-owned foreground precedence and internal scrolling.

All H10B production declarations require landscape and height at most 500px. Protected Portrait sizes cannot match. At 1440×900 H2/H3 retain the centered bounded shell and Location Context/dock relationship. Presentation state is memory-only, resets on short-landscape entry, is removed on orientation return, and KBYG close returns collapsed.

## Acceptance boundary

Automated contracts certify source, runtime wiring, breakpoint arithmetic, accessibility semantics, owner reuse, and protected-authority noninterference. Owner browser acceptance remains required at 932×430 and 844×390, followed by 320×700, 390×844, 430×932, the 390×844 → 844×390 → 390×844 rotation sequence, and 1440×900. Automated checks are not a rendered visual pass.
