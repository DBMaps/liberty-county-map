## State contracts

Collapsed is the default each time the short-landscape media query is entered. Gridly identity, current Community Pulse status, KBYG, all five filters, the mounted map, map controls, and the small handle remain visible. Location Context/Search and the four-action dock are visually hidden, `aria-hidden`, inert, and noninteractive.

Expanded state raises the existing Location Context/Search owner above the existing one-row Report, Alerts, History, and Settings dock. The height is bounded to the two compact rows; map padding changes so useful map area remains above. The accessible button controls both existing regions, reports `aria-expanded`, changes between explicit Show/Hide labels, and uses decorative up/down chevrons. State is memory-only for the current short-landscape session and resets on entry; it never reaches storage or product settings.

## Foreground behavior

Search continues through `openGridlyDestinationSearchSurface`. Report, Alerts, History, and Settings continue through the Portrait V2 sheet handlers. Existing H5 foreground authority remains in place, while H8 additionally suppresses the bottom region during a foreground workspace. Closing the existing surface reveals the map and retains expanded state while the media query remains active.

## Portrait isolation

All production geometry and visibility changes are inside the short-landscape media query. The handle defaults to `display: none` outside it. On leaving the query, H8 removes `inert`, `aria-hidden`, and its expanded body class, restoring the accepted Portrait DOM and geometry at 320×700, 390×844, and 430×932.

## LP243.H9 addendum — interaction completion

### Missing-disclosure RCA and final authority

The first losing stage was committed source markup, not a template, cleanup, or late DOM replacement. H8 implemented `#gridlyLandscapeCommandHandle`, while owner certification queried the different, undocumented `#gridlyLandscapeCommandToggle`; H8's static test repeated the implementation selector and therefore never detected that certification-contract mismatch. `#gridlyPortraitBottomDock` was likewise not an implemented owner—the current dock remains `#gridlyLandscapeCommandPanel`. The visible chevron was the decorative `⌃` span inside the undersized H8 handle, not a pseudo-element or a legacy control.

H9 names the one current disclosure owner `#gridlyLandscapeCommandToggle`. It is a native button controlling the real `#mobileDestinationCommandPanel` and `#gridlyLandscapeCommandPanel`, with synchronized `aria-expanded`, explicit Show/Hide labels, a 44px minimum hit target, native keyboard activation, and a visible `:focus-visible` outline. No template or runtime clone exists.

### Fail-open and live hit-test rule

`gridlyLandscapeCommandDisclosureAudit()` certifies the active runtime owner—not merely source text—by checking connection, button type, enabled state, computed display/visibility/pointer events, viewport containment, center-point hit testing, and the production binding marker. `syncGridlyLandscapeCommandPanel()` may apply `inert` and `aria-hidden` only when that complete contract passes. If the disclosure, Location Context, or dock owner is absent, or the disclosure is not actually reachable, H9 removes accessibility suppression and applies the visible fail-open presentation instead.

### KBYG short-landscape foreground contract

The KBYG lifecycle and intelligence remain unchanged. The geometry defect was inherited Portrait expansion: a 430px-high panel retained normal-flow top position at 99px, producing a 529px bottom in a 430px viewport. In short landscape only, the same `#gridlyBriefInteractionPanel` becomes a fixed, centered foreground card between safe top and bottom gutters, capped below `100dvh`, horizontally bounded, and internally scrollable. Its existing `#gridlyBriefFoundationHandle` becomes a fixed 40px foreground collapse control above the card. The panel outranks map chrome while underlying map ownership stays mounted.

When KBYG opens, H9 records and temporarily collapses an expanded command panel and makes the command, Location Context, filter, and map controls noninteractive/hidden beneath the foreground. Closing KBYG restores the prior command expansion when its runtime disclosure remains safe; otherwise the command lifecycle fails open. Search and the Report, Alerts, History, and Settings sheet handlers are not modified.

### Portrait isolation and H8 protection

Every H9 geometry selector is inside `(orientation: landscape) and (max-height: 500px)`. Viewports 320×700, 390×844, and 430×932 cannot match it. H9 retains H8's default map-first composition and existing expanded Location Context/Search plus four-action dock; it completes disclosure authority and KBYG foreground containment without changing data, feature, map, filter, or storage authority.
