# LP243.I2.1S2 — Esri Imagery Labels activation

Gridly composes the existing Esri World Imagery raster with **ArcGIS Static
Basemap Tiles — ArcGIS Imagery Labels**. The only new production network
authority is `static-map-tiles-api.arcgis.com`; no geocoding, routing, Places,
static-map, analytics, or user-specific application data is added.

## Service contract

- Endpoint: `https://static-map-tiles-api.arcgis.com/arcgis/rest/services/static-basemap-tiles-service/v1/arcgis/imagery/labels/static/tile/{level}/{row}/{column}`
- Authentication: API key or short-lived token through the `token` query parameter.
- Gridly credential: browser-visible public-application API key, injected at runtime, referrer-restricted, and granted only `premium:user:staticbasemaptiles`.
- Tiles: PNG, 512 x 512.
- Path semantics: level / row / column. In Leaflet placeholders this is `{z}/{y}/{x}`.
- Scale alignment: `tileSize: 512` and `zoomOffset: -1`; Esri's static-tile level is one less than a traditional 256px tile API at the equivalent scale.

The tracked `arcgisStaticBasemapApiKey` value is blank. When it is absent or
blank, Gridly never constructs the labels layer and Satellite remains the
unchanged Esri World Imagery basemap. A tile request failure removes the label
child from the logical Satellite group, leaving imagery usable. The dedicated
non-interactive pane is above imagery and below Gridly features. Switching
removes/adds the single logical Satellite group, preventing stale or duplicate
labels and attribution.
