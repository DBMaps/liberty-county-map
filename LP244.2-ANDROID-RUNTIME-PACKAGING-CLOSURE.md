# LP244.2 Android runtime packaging closure

## Root cause

`tools/native-web.mjs` previously copied the complete `css`, `js`, `assets`,
`data`, `Community-Packages`, and `Crossing-Packages` trees. Its denylist only
recognized platform, tool, test, report, evidence, and owner-local path names.
Manufacturing products stored under otherwise public-looking paths therefore
passed the filter. The defect was both an over-broad inclusion model and an
incomplete, indefinitely growing exclusion model.

The replacement is a consumer-runtime allowlist. Static UI files are named by
file or bounded tree. Statewide package manifests, crossing package files, the
address runtime package, and POI shards are expanded from their governed
manifests. Adding a repository file no longer adds it to an APK implicitly.

Allowlisted trees are filtered recursively: every descendant must satisfy the
same prohibited-path policy as its tree root. In particular,
`js/gridly.local.js` remains an optional owner-local browser input and is never
staged, while production JavaScript and the governed
`js/gridlyRuntimeEnvironmentConfig.js` composition authority remain included.

## Classification

| Class | Native policy |
| --- | --- |
| HTML, current CSS, JavaScript, local Leaflet/Supabase, artwork | Included direct runtime |
| County geometry, canonical crossings, San Antonio regions, roadway manifest | Included generated runtime/indexes |
| 254 production crossing packages and repository-backed community manifests | Included from statewide runtime registries |
| POI manifest and all 86 certified gzip shards | Included certified runtime |
| POI `.bin` copies | Included byte-identical serving aliases required by the Capacitor Android local server |
| Liberty TXGIO gzip and certificate | Included because the address runtime manifest fetches them |
| Other TXGIO gzip and every raw `.addresses.jsonl` | Excluded manufacturing output; the runtime manifest does not name them |
| Census shapefile components and county source trees | Excluded source evidence/manufacturing inputs |
| County boundary GeoJSON and directly configured county runtime files | Included generated runtime |
| San Jacinto road-segment GeoJSON under legacy `source/` | Included sole named exception because the consumer directly fetches it |
| Other raw road-segment/source OSM/directional evidence | Excluded manufacturing/source/audit material |
| CSS backups, evidence, audit, certification, owner-local files | Excluded non-runtime material |

No source or certification asset is deleted from the repository. The change is
limited to staging policy and its packaging contract.

## Regression budget

Verification repeats staging and compares a path/size/content SHA-256 identity.
It also rejects more than 1,200 staged files or 300 MiB of staged bytes, rejects
forbidden path classes, checks the certified 86-shard POI authority and Dayton
cohort, and reports exact file count, byte count, and bundle digest.

The pre-repair APK baseline is 776,153,212 bytes (740.20 MiB), with 1,849
`assets/public` files, 3,179.37 MiB uncompressed assets, and 735.69 MiB
compressed assets. APK closure must be compared with that baseline after a JDK
21 / Gradle 8.14.4 build; staging closure alone is not an APK-size claim.
