# LP104.3 — Texas address measurement

## Stable measurement design

LP104.3 measures NAD R23 in place and read-only through GDAL `/vsizip/`; it never extracts, modifies, or dumps the archive. The previous design forced `OpenFileGDB`, requested JSON, set `LIST_ALL_TABLES=NO`, selected the SQLite dialect, and ran a national `GROUP BY State`. QGIS 3.44.11 `ogrinfo.exe` crashed with Windows access violation `0xC0000005` during that first aggregation, so that entire ordinary-read pattern has been removed.

The revised tool first uses the already-proven minimal schema command. It then establishes the three required proofs using native OpenFileGDB attribute filters:

1. `State = 'TX'` with `-where -so`, parsing `Feature Count`;
2. `State = 'TX' AND County = 'Liberty'` the same way; and
3. a bounded address-number, street, city, and ZIP filter for `274 County Road 677, Dayton, TX 77535`, again parsing only `Feature Count`.

No national state inventory is needed because `State` is a two-character source field and the owner explicitly supplies `TX`. National state-value inventory is reported as deferred rather than inferred. After the three core proofs, optional county counts iterate Gridly's existing official 254-county identity list and perform one native filtered count per county. The list supplies iteration names and FIPS identities only; every reported count comes from NAD. `--core-only` skips this optional stage.

Every invocation is bounded to summary output and contains `-ro`. Routine counts do not contain `-if`, `-json`, `-oo`, `-dialect`, or `-sql`. `--debug` prints every attempted strategy, executable, and exact argument array. The JSON report also records succeeded and failed attempts. Reports are checkpointed after the core proofs and after each optional county attempt, so an optional failure yields an honest partial report rather than erasing completed evidence.

## Run and owner retest (PowerShell 5.1)

Run this block from the repository. It intentionally runs the three direct probes before the Node tool.

```powershell
$ErrorActionPreference = 'Stop'
$OgrInfo = 'C:\Program Files\QGIS 3.44.11\bin\ogrinfo.exe'
$Archive = 'C:\GitHub\Gridly-Source-Data\National-Address-Database\NAD_r23.zip'
$DataSource = '/vsizip/C:/GitHub/Gridly-Source-Data/National-Address-Database/NAD_r23.zip/NAD_r23.gdb'
$Reports = Join-Path $PWD 'reports\lp104.3-owner-retest'

# 1. Texas filtered feature count
& $OgrInfo $DataSource -ro -so -where "State = 'TX'" NAD
if ($LASTEXITCODE -ne 0) { throw "Texas probe failed with exit code $LASTEXITCODE" }

# 2. Liberty filtered feature count
& $OgrInfo $DataSource -ro -so -where "State = 'TX' AND County = 'Liberty'" NAD
if ($LASTEXITCODE -ne 0) { throw "Liberty probe failed with exit code $LASTEXITCODE" }

# 3. Bounded target-address feature count (no feature dump)
$TargetWhere = "State = 'TX' AND County = 'Liberty' AND (Add_Number = '274' OR Add_Number = 274) AND (StNam_Full LIKE '%COUNTY ROAD 677%' OR StNam_Full LIKE '%COUNTY RD 677%' OR StNam_Full LIKE '%CR 677%') AND (Post_City = 'Dayton' OR Post_City = 'DAYTON') AND (Zip_Code = '77535' OR Zip_Code = 77535)"
& $OgrInfo $DataSource -ro -so -where $TargetWhere NAD
if ($LASTEXITCODE -ne 0) { throw "Target-address probe failed with exit code $LASTEXITCODE" }

node .\tools\lp104\measure-nad-r23.mjs --archive $Archive --reports $Reports --gdal $OgrInfo --state TX --county Liberty --debug
if ($LASTEXITCODE -ne 0) { throw "LP104.3 tool failed with exit code $LASTEXITCODE" }

Get-ChildItem -LiteralPath $Reports -Filter 'lp104.3-nad-r23-*' | Select-Object Name,Length,LastWriteTimeUtc
```

## Expected reports and decision gate

The tool writes `lp104.3-nad-r23-texas-measurement.json`, a concise Markdown report, and `lp104.3-nad-r23-texas-counties.csv`. A complete run has all 254 optional county counts. A partial run still contains Texas, Liberty, and target counts plus limitation and failed-probe metadata; unavailable county rows have a blank count and `unavailable` status.

The national State distribution, completeness aggregates, high-cardinality distributions, and feature candidate payloads remain deferred until a separately proven stable bounded design exists. Do **not** recommend merge or ingestion from this implementation alone. Owner retest is ready, but merge remains blocked until the real Texas and Liberty counts both succeed and are reviewed.
