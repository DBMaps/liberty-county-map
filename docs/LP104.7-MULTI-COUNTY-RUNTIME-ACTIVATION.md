# LP104.7 — Certified multi-county runtime activation

LP104.7 extends the TxGIO address runtime from its Liberty-only selector to the 28 supported Gridly counties. Address intent is still required, and a query must contain an exact house number plus a canonical road. County selection uses an explicit supported county/locality or the existing active-county context; an explicit unknown ZIP remains ineligible. Business/place intent never enters the runtime.

The runtime manifest, certificate, and address artifact are read only after an eligible exact-address request. The shared manifest promise is cached. Each selected county has its own promise cache keyed by FIPS, and only that county's certificate and artifact are requested. A failed load is evicted so transient delivery failures can recover. No county artifact is requested at script installation or application startup.

Before indexing, the runtime requires manifest identity and integrity metadata, fetches the entry's runtime certificate, checks county/FIPS/artifact/size/digest agreement and the certified exact-match policy, and then verifies the downloaded gzip size and SHA-256. Records outside the selected FIPS are not indexed. Lookups remain exact `HOUSE|CANONICAL ROAD`; interpolation and nearby-house substitution remain prohibited.

## Browser certification

From the browser console, run:

```js
await window.gridlyCertifyLp1047MultiCountyRuntime()
```

The helper returns `startupPackageLoads`, `loadedCountyPackages`, `cachedCountyPackages`, `packageReusePass`, `lazyLoadingPass`, `countySelectionPass`, `exactAddressPass`, `truthfulNoResultPass`, `businessSearchPass`, and `overallPass`, plus case and runtime evidence. A custom certified case matrix can be passed as `{ cases: [[query, expectedOutcome, optionalCountyId], ...] }`.
