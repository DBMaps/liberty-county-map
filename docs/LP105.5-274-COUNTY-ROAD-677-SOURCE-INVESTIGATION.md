# LP105.5 — 274 County Road 677 source investigation

## Decision

**Outcome D — source conflict.** Denise has confirmed that `274 County Road 677, Dayton, Texas 77535` is her real address. The complete repository-available certified TxGIO-derived Liberty snapshot has no exact 274 record on that road, while it has an exact 276 record. The original TxGIO File Geodatabase and locally calculated NAD R23 reports are not present in this checkout, so this investigation cannot truthfully elevate package absence into proof that every governed source is absent. No address, coordinate, package, or certificate was manufactured or rebuilt.

## Verified source evidence

* The governed source descriptor identifies TxGIO 2026 Statewide Address Points, layer `stratmap_2026_address_points_48`, with 12,142,647 statewide records. Its configured original GDB is an external Windows path, not a repository artifact.
* The builder selects every Liberty feature by FIPS 48291. It rejects only a missing exact house number, canonical road, full address, coordinates, or a conflicting FIPS. Deduplication is only by the deterministic identity made from FIPS, house, street, full address, and coordinates; a duplicate always leaves its first identical record in the package.
* The local, ignored build sidecar reports 82,444 source rows read, 82,443 accepted, zero rejected, and one duplicate. This is useful execution evidence but is not committed evidence and cannot replace a new read of the governed GDB.
* The NAD R23 measurement tool contains a bounded exact query for 274/County Road 677/Dayton/77535, but its generated reports and NAD archive are deliberately ignored and absent. No NAD result is claimed.

## Verified repository and package evidence

* SHA-256 of the checked-in Liberty gzip is `792f4f3f76524ef6652fbabf7c1c17d76eb1dfd9d83a71c460c1e038c2841b93`; its size is 2,555,016 bytes. Both runtime and manufacturing certificates agree.
* The gzip passes decompression and contains 82,443 JSONL records, matching the certification count. It contains 23 records whose canonical road/locality/ZIP/FIPS are exactly `COUNTY ROAD 677` / `DAYTON` / `77535` / `48291`.
* That exact group contains zero house 274 records, zero house 275 records, and one house 276 record. The 276 record ID is `0111abad4b63b47be1c4`, at longitude `-94.932829`, latitude `30.131114`, sourced to Houston-Galveston Area Council with source update `20170809`.
* A package-wide search finds no 274 under a spelling or alias of road 677. All package road-677 records use the same canonical road, locality, ZIP, county, and FIPS, so no package alias/locality/ZIP representation explains the miss.
* Certification reports 3,000/3,000 sampled exact matches, 3,000/3,000 truthful incorrect-number misses, zero interpolation, zero nearby-number substitution, zero duplicate identities, zero outside-county records, and zero invalid records.
* Git history shows that the prior negative-control decision was based on package evidence. It does not contain a committed direct TxGIO or NAD source-query result proving 274 absent.

## Inference

Given the builder's selection and identity rules and the local zero-rejection sidecar, the available evidence is consistent with 274 being absent from the TxGIO snapshot used for manufacturing, rather than being rejected, normalized away, or deduplicated out. That is an inference, not direct source proof, because the original GDB cannot be queried here.

## Unresolved gaps and authoritative-source strategy

1. Re-run a read-only exact query against the immutable TxGIO GDB used to create this package and retain a versioned query report containing source identity/digest, layer, predicate, feature count, and any exact feature fields.
2. Run the existing bounded NAD R23 exact query and retain its versioned report with the archive release and digest.
3. If either source returns 274, compare the raw feature to the builder inputs and perform only a targeted, deterministic Liberty rebuild from that governed source. If neither returns it, pursue a licensed and versioned Liberty County 911/address-point authority or an approved TxGIO correction; do not insert a resident-provided coordinate into the certified package.
4. Until direct source evidence resolves the conflict, the runtime must truthfully return no result for 274 from this certified snapshot. It must not interpolate, substitute 276, or claim that the real address does not exist.
