# LP108.12 — Harris Independent Bucket Objects

LP108.12 replaces Harris runtime use of the 65,091,011-byte combined sidecar with a deterministic manifest and 256 private gzip objects. The manifest is bound to the unchanged Harris runtime package by its 1,452,427-record identity, 57,731,771-byte size, and SHA-256 `80a474e6f63edd0bf51d282822132bce48a985c020b1f97f32479fd3221e8d1b`. Runtime verifies the existing certificate first, then the manifest identity, then downloaded bucket bytes before examining a record. There is no combined-container or source-package fallback.

## Measured local artifact profile

The clean local build produced 256 buckets totaling 65,089,143 compressed bytes. Bucket compressed sizes were 244,054 bytes minimum, 264,260 maximum, 254,254.46 average, and 259,122 bytes for representative bucket `80`. The largest bucket contains 5,895 records. A representative local read, SHA-256, decompression, and scan setup averaged 12.6 ms over 20 runs; a request scans at most the selected bucket's governed record count. No bucket approaches the Supabase object limit that rejected the former 65 MB boundary: the largest is about 0.41% of the combined container. Actual deployed latency remains owner certification evidence and is not claimed here.

## Owner PowerShell sequence

Run from the repository root. The first four commands concern private Storage; replacement remains opt-in and is not shown.

```powershell
# 1. Build
npm run build:lp10812:harris-buckets

# 2. Local verification
npm run verify:lp10812:harris-buckets
npm run test:lp10811

# 3. Upload/resume (matching objects are skipped; an interrupted run is safe to repeat)
npm run upload:lp10812:harris-buckets

# 4. Remote byte verification
npm run verify-remote:lp10812:harris-buckets

# 5. Deploy
npx supabase functions deploy gridly-geocode --project-ref $env:SUPABASE_PROJECT_REF

# 6. Harris-only certification
node tools/lp108/certify-remote-runtime.mjs --county-fips 48201

# 7. Full 28-county certification
node tools/lp108/certify-remote-runtime.mjs
```

Required secrets (`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, and certification `SUPABASE_ANON_KEY`) remain environment-only. Do not paste them into arguments or logs. This implementation did not deploy, upload, or run authenticated certification.
