## LP135 logical CSV validation

LP135 normalizes CRLF and lone CR line endings to LF before comparing generated inventory
text. Regression coverage submits both an LF fixture and its CRLF equivalent, proves their
normalized inventories are identical, and proves a certification-status change is rejected.
Row count, county identity, status, evidence references, and deterministic ordering remain
covered by the generated report reconciliation and full logical CSV comparison.

## LP130 dry-run isolation

The side effect originated in `run()` calling `writePlan()` unconditionally: the LP130 test
passed the completed 254-package live manifest, so the dry run overwrote governed evidence
with a zero-batch plan. Dry runs now write only beneath the caller's `--reports` directory.
The test creates an OS temporary directory with `mkdtemp`, compares governed batch-plan bytes
before and after the run, and removes the directory in `finally`.
