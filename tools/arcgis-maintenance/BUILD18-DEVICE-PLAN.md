## Private diagnostic

1. On a private offline owner workstation, create an Ed25519 signing pair. Keep its private key outside the repository, CI, phone, and reports. Supply only its raw 32-byte lowercase hex **public** key as the reviewed diagnostic archive setting GRIDLY_BUILD18_OWNER_PUBLIC_KEY; verify that exact value in the signed Info.plist and both diagnostic compile flags. Without this key, the import UI is unavailable. Do not configure it in ordinary Release.
2. After an authorized in-place installation, open the native owner panel (two fingers, three seconds). Use its displayed public run challenge. The owner-side sealBuild18Candidate function takes the private buffers returned by readMaintenanceProviderInputs after platform-specific private-file checks. It repeats validateProviderPair before sealing: original ArcGIS must differ and DriveTexas must match. Sign only the reviewed candidate. Do not print or persist the grant alongside the file; keep it with the owner on a separate private channel. No provider credentials are part of the app package.
3. Place only the encrypted .gridlycandidate file in local Files on the iPhone, using an approved local transfer. Do not select iCloud or a third-party cloud location. Return to the same owner panel; if iOS terminated the app, obtain a new challenge and envelope. While foregrounded, select the file, enter the signed one-time grant in the secure native field, and tap **Approve native diagnostic**. No one should collect a grant, file path, raw token, URL, provider body, or a screenshot of entry.
4. Verify INSTALLED_UNARMED; no request should occur. Only after separate live authorization, tap **Arm**, then request the fixed native TLS tile at service level/row/column **12/1689/968** (Dayton, Texas). At most two attempts, one in flight, no retries after an error, and no repeat import. The 15-minute envelope expiry and five-minute maximum foreground use both apply. Close/background/lock and confirm the run cannot resume. The app clears its owned mutable plaintext and request buffers where practical; Swift, CryptoKit, UIKit, and Network may retain transient copies.
5. Report only native context, ordinal 1 or 2, HTTP status, content class, and 512-by-512 decode pass/fail. A native TLS result does not establish ordinary WKWebView HTTPS authorization.

The envelope is raw AES-256-GCM combined data (12-byte nonce, ciphertext, 16-byte tag); the plaintext contains only a ten-digit expiry and the replacement ArcGIS value. Authenticated data binds the Gridly bundle, marketing version, build, live run challenge, and candidate SHA-256. The Ed25519 signature binds the full envelope to the grant and the archive's owner key. The existing exclusive, durable run ledger rejects a second import without persisting a credential.

## Native tests: one exact execution on a disconnected Mac

Use the real App target and the shared GridlyBuild18Diagnostics scheme. Authorize one run on a disposable macOS/Xcode 26.5 (17F42) environment with the iOS 26.5 simulator already installed. Use an exact reviewed commit and one known simulator UDID. Use Build 17's locked dependencies, native assets, canonical web stage and byte verification, Capacitor sync, verified 16.4 SPM manifest, and package resolution. Do not provide a provider overlay, owner public key, private grant, signing configuration, or an Apple account.

Before boot or test launch, have the operator disconnect the disposable Mac or VM from external networking independently of the guest; verify the absent uplink and denied IPv4 and IPv6 routes with numeric, operator-owned controls. Keep loopback only. Abort if either family cannot be proven isolated. The actual hosted App can start its ordinary web view even though the XCTest inputs themselves are synthetic. Do not use the previous hosted PF path.

Use one disposable DerivedData directory and one package cache. Preload dependencies before disconnection. Once isolated, use the following command from the checked-out root, with REVIEWED_SIMULATOR_UDID, PRIVATE_DERIVED_DATA, and PRIVATE_SWIFT_PACKAGES set to the reviewed values. Bound the entire test attempt to 10 minutes and keep isolation until the simulator is shut down and its state erased.

    xcodebuild -project ios/App/App.xcodeproj -scheme GridlyBuild18Diagnostics \
      -configuration Debug -destination "platform=iOS Simulator,id=$REVIEWED_SIMULATOR_UDID" \
      -derivedDataPath "$PRIVATE_DERIVED_DATA" -clonedSourcePackagesDirPath "$PRIVATE_SWIFT_PACKAGES" \
      -disableAutomaticPackageResolution -parallel-testing-enabled NO -maximum-concurrent-test-simulator-destinations 1 \
      CODE_SIGNING_ALLOWED=NO ENABLE_TESTABILITY=YES \
      SWIFT_ACTIVE_COMPILATION_CONDITIONS='DEBUG GRIDLY_ARCGIS_DIAGNOSTIC GRIDLY_BUILD18_DIAGNOSTIC' test

Do not retry. Capture only per-test pass/fail and fixed failure class; no raw XCTest or app logs, bundle retention, or provider access. Also run the established 14 Foundation recovery lifecycle cases with --build18. No GitHub job was added; an isolated native environment is a prerequisite, not something this source change establishes.

This path is blocked until the owner approves a provider-supported browser authorization that keeps the private candidate out of JavaScript (or explicitly approves a different reviewed browser credential policy). Use the actual Gridly WKWebView and observed headers; do not synthesize Referer or Origin.
